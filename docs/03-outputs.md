# 03 · 工作产出

## 一、数据产出（4 张表）

### `profiles` · 求职画像

一次完整流程产出 1 条激活画像（`is_active=true`），历史版本保留。

```jsonc
{
  "target_profile": {
    "roles": ["数据平台工程师", "后端开发工程师"],
    "level": "高级/资深",
    "industries": ["互联网", "云计算"],
    "cities": ["杭州", "成都"],
    "cities_en": ["Hangzhou, China", "Chengdu, China"]
  },
  "keywords": ["实时计算", "数据湖", "后端开发"],
  "keywords_en": ["Backend Engineer", "Data Platform Engineer", "Stream Processing"],
  "competitiveness": [
    "8 年后端与数据平台经验",
    "TB 级实时数据链路落地 5+ 个",
    "2 年 AI 基建从 0 到 1"
  ],
  "gaps": ["缺少大规模分布式训练经验"],
  "confirmed": true
}
```

### `jobs` · 岗位池

一个岗位一条记录，贯穿「待确认 → 待投递 → 已投递 → 已查看 → 面试中/不合适」全生命周期。

| 分组 | 字段 |
|---|---|
| 身份 | `company` `position` `platform` `source_url` |
| 条件 | `salary` `location` `jd_summary` `jd_text` |
| 评估 | `match_score` `match_reason` |
| 状态 | `status` `created_at` `updated_at` |

典型一轮产出的量级：猎聘 3 词 × 约 40 条 + 领英 3 词 × 约 25 条 ≈ 150 条候选，去重后新增 10-60 条（同一岗位池每天重复率很高，这是正常的）。

### `job_events` · 事件流

每个岗位的完整历史，支持回溯。

| event_type | 何时写入 | note 示例 |
|---|---|---|
| `授权投递` | 你点授权 | 你手动确认授权，简历将投递至该岗位 |
| `已投递` | 你点「我已手动投递」 | 你在猎聘上手动完成投递，开始跟踪 |
| `状态变化：待投递→已查看` | 反馈同步 | 猎聘官方状态同步 |
| `状态变化：待确认→已投递` | 反馈同步 | 猎聘官方状态同步 |
| `放弃投递` | 你点「不投了」 | 你在确认清单中选择了不投递 |
| `恢复待确认` | 你点「↩ 移回待确认」 | 你从不投清单将岗位移回待确认 |

### `agent_tasks` · 运行记录

每轮采集一条，你在应用里能直接看到四态。

| status | note 形态 |
|---|---|
| `processing` | `定时采集运行中` |
| `done` | `猎聘入库18条/领英入库9条/重复126个/清理重复0条/打分27条` |
| `failed` | `失败原因：领英重定向linkedin.cn` |
| `merged` | `已合并：与同一时段正在进行的采集合并执行` |

## 二、界面产出（4 个主步骤 + 4 个辅助入口）

| 页面 | 关键产出 |
|---|---|
| ① 简历画像 | 解析结果、结构化画像、竞争力/缺口、多轮对话记录、「确认画像」状态 |
| ② 岗位池 | 待确认岗位列表（按分数倒排）、导入框、批量打分、**一键去重**、**手动触发采集**、**运行采集记录** |
| ③ 投递清单 | 三个页签（最新岗位清单 / 已确认投递 / 不投的岗位），各带数量角标；每条含完整职位链接 |
| ④ 跟踪仪表盘 | 统计卡、投递漏斗、面试邀请列表、事件时间线、刷新状态 |

**每个岗位卡片固定包含**：平台徽章 · 公司 · 岗位名 · 匹配度 · 匹配理由 · 岗位预算 · 工作地点 · 岗位来源 · 🔗 职位链接 · JD 摘要 · 操作按钮。

## 三、消息产出（每天 2-4 条）

### 采集完成汇总

```
本轮采集 18:00 完成
· 猎聘：3 个关键词，新入库 18 条
· 领英：3 个关键词，新入库 9 条
· 因已存在跳过 126 个（其中已投递 3 个 / 已拒绝 8 个）
· 自检清理重复 0 条
· 已自动打分 27 条

最高分：星辰数据 · 资深后端专家 90 分 / 云脉科技 · 数据平台架构师 78 分 / 北岸软件 · 后端开发 58 分
👉 去「③ 投递清单 · 最新岗位清单」查看
```

### 采集失败

```
失败原因：领英重定向linkedin.cn
处置：请开启全局代理（TUN）后重新点「⚡ 通知 Agent 立即采集」
```

### 反馈同步

```
投递反馈已更新
· 新增已查看 2 条
· 面试邀请 1 条：星辰数据 · 后端开发工程师
```
