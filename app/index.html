🎯 投递助手

第 1 步 · 上传/粘贴简历，AI 提炼核心竞争点与岗位画像

支持直接粘贴简历文本，或上传 .txt 文件。分析结果将作为后续岗位匹配的依据。安全提示：提交时会自动隐藏手机号、身份证号、银行卡号；家庭住址等敏感信息建议粘贴前自行删除。

支持 Word（.docx）、PDF、Markdown/TXT、图片（JPG/PNG 等，自动 OCR 识别中文简历）；全部在浏览器本地解析，仅脱敏后的文字会参与分析。

第 2 步 · 手动导入岗位（书签 JSON / 粘贴 JD，自动识别）

两种内容粘贴到同一个框，点一次「智能导入」即可：① 书签采集的内容（JSON 数组）→ 直接批量去重入库；② 复制的职位描述（JD）→ AI 解析出公司/岗位/薪资/地点后入库，多个 JD 用单独一行 --- 分隔。想全自动可用上方「⚡ 通知 Agent 立即采集」。

⚡ 手动触发 Agent 自动采集（免等定时点）

定时任务每天 8:00 / 18:00 自动「采集 + 打分」。两次之间若想立即找新岗位，点下面的按钮：系统向 Agent 发出采集请求，Agent 按你的当前画像执行一轮「猎聘 3 中文词 + 领英 3 英文词」采集、去重入库并自动打分，完成后给你发汇总消息。请求检查点每小时整点运行，平均等待约 30 分钟。

第 3 步 · 确认投递清单（公司 + 岗位 + JD 摘要 + 岗位预算 + 工作地点 + 岗位来源）

本清单按匹配度从高到低倒序排列，仅显示尚未授权的岗位；你点击「授权投递」过的岗位会自动移入上方「已确认投递」页签。勾选你同意投递的岗位后点击「批量授权」，授权后请到对应平台（猎聘/领英，见「岗位来源」）完成投递，回来点击「已手动投递」，系统才会记录并开始跟踪。

已确认投递（已授权，等你在对应平台完成手动投递）

这里只显示你已点击「授权投递」的岗位，同样按匹配度倒序排列；投递完成后点「我已手动投递」，岗位进入第④步跟踪仪表盘。

不投的岗位（你已跳过，不再进入投递清单）

这里显示你在「最新岗位清单」里点击「不投了」而跳过的岗位，按匹配度倒序排列；每条都保留了原始职位链接，方便你随时回看或反悔。如需重新投递，点击「↩ 移回待确认」即可回到最新岗位清单。
